# Глоссарий

> **Status**: living
> **Last updated**: 2026-07-19

Термины определяются здесь один раз (Принцип 3) и везде используются по имени. Новый термин сначала вводится сюда, потом в спеки.

## Участники

- **Ученик** — русскоязычный IT-профессионал, изучающий американский английский для работы, переписки и TOEFL.
- **Преподаватель (агент)** — LLM-агент (Codex или Claude Code), ведущий сессию. Сменяемый исполнитель роли; не источник истины о прогрессе.
- **Движок** — Python-приложение, единственный управляющий орган: владеет состоянием, scoring, расписанием и рекомендациями.

## Обучение

- **Сессия** — одно занятие. Жизненный цикл: `STARTED → IN_PROGRESS → FINISHED`; внутренняя структура свободная, обязательна только фиксация результатов при завершении.
- **Тема (Topic)** — единица curriculum со стабильным ID вида `grammar.present-perfect.result`.
- **Skill dimension** — измерение владения темой: recognition, controlled production, transfer, spontaneous written production (текстовые модальности MVP).
- **Curriculum graph** — DAG тем с prerequisites. В нашей модели — карта и источник рекомендаций, не система замков ([PD-2026-07-19]: prerequisites рекомендательные).
- **Chunk** — устойчивое выражение/фраза, изучаемая как целое.

## Оценивание

- **Attempt** — одна попытка ученика (ответ, фраза, упражнение).
- **Evidence** — сохранённое свидетельство владения: исходный ответ + контекст + оценка. Каждая оценка обязана иметь evidence; упоминание темы — не evidence.
- **Mastery** — качество владения темой, 0–100. Меняется только scoring engine.
- **Stability** — предполагаемая устойчивость знания в днях.
- **Retrievability** — вероятность воспроизведения сейчас, 0–1.
- **Review** — повторение темы; результат классифицируется как `PROGRESS / CONFIRMED / REGRESSION / RECOVERED / INSUFFICIENT_EVIDENCE`.
- **Gate** — добровольная формальная проверка готовности (topic/module/CEFR boundary). Рекомендация, не барьер.
- **Placement** — внутренняя CEFR-aligned диагностика стартового уровня (текстовые модальности). Короткая (~30–40 мин) с rolling-уточнением по первым сессиям [PD-2026-07-19].
- **Re-entry протокол** — после длительного перерыва движок рекомендует начать сессию с быстрого повторения или короткого теста остаточных знаний; отказ допустим и не штрафуется.
- **Банк упражнений** — накапливаемые из сессий удачные сгенерированные упражнения с метаданными; переиспользуется для повторений, пустой банк ничего не блокирует.

## Метрики

- **Learning Score** — агрегированное владение программой.
- **Season XP** — дисциплина: выполненные планы, бонусы, штрафы. Не влияет на Mastery/CEFR.
- **Tutor Compliance Score** — соблюдение программы AI-преподавателем.

## Система

- **Session Manifest** — сформированный движком план сессии: рекомендации тем, повторения с `review_id`, required skills с версиями.
- **Event log** — append-only JSONL журнал всех значимых действий; источник для replay.
- **Learner-память** — генерируемая движком Obsidian-проекция состояния ученика (`memory/`). Читаемая проекция, не источник scoring. Не путать с вики разработки.
- **Skill (агентский)** — процедурная инструкция для агента в `agent-skills/`, синхронизируется в `.agents/skills/` и `.claude/skills/`.
