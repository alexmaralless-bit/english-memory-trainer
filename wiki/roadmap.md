## История изменений

- **2026-07-21 (47)**: **kernel 1.2, инкремент 2 — доставка outbox + производный JSONL-экспорт.** `kernel/outbox.py`: `Consumer`/`Reconcilable` протоколы, `OffsetStore` (per-consumer high-water mark в новой таблице `consumer_offsets`, миграция v2), `deliver()` — строго по `sequence`, offset двигается атомарно с эффектом (SQLite-consumer → exactly-once; внешний эффект → at-least-once + reconcile), монотонный advance не откатывает прогресс, прерванная доставка resumable. `kernel/export.py`: `JsonlExporter` — канонический append-only JSONL (derived, не источник истины), `reconcile()` усекает хвост за committed offset (crash между append и commit), `rebuild()` — byte-идентичный полный пересбор из event-таблицы. `kernel/check.py`: `database_check()` — FK + схема + сверка event↔JSONL **только до acknowledged offset**, отставание = `pending`, не integrity-error (§2.1). +16 тестов (53 kernel / 64 всего), ruff + mypy strict чисты. Отложено: isolate-and-swap для SQLite read-model проекций, typer-CLI-обёртка. **Ждёт независимого ре-ревью вместе с инкрементом 1.**
