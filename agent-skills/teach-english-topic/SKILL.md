## Steps

1. Опора — `brief.central_topic`: `can_do`, объяснительные факты
   (`core_points`, `contrasts`, `error_patterns`, `scope_limits`,
   `memory_insights`), `examples`, `typical_errors`, фреймы с `meaning_ru`.
   Для сопутствующей темы факты читаются `curriculum show --topic <id>` /
   `curriculum lexicon` до старта урока.
2. **Фреймы перед формой.** Если у темы есть фреймы, показать 4–6 из них
   (`title` со слотом `___` и `meaning_ru`) ДО компактной формы; затем
   retrieval bridge: ученик печатает два фрейма по русской реплике, не видя
   формы. Тема без фреймов этот шаг пропускает.
3. Форма объяснения зависит от профиля. `program_lesson`/`vocabulary` —
   полная дуга из pedagogy.md (ситуация → смысл → компактная форма → контраст
   → 3–4 разобранных примера → ловушки с причиной → граница и 1–3 частых
   исключения → retrieval-вопрос). `practice`, `spaced_review`, `drill` —
   после фреймов целевая форма ОДНОЙ строкой; полное объяснение — в дебрифе
   (им владеет вызывающий skill).
4. **Адаптация.** Если ученик говорит «я это знаю» — одно-два проверочных
   задания; справился — пропустить остаток объяснения и перейти к практике.
5. Использовать `memory_insights`. Если их нет, исследовать только
   потенциально полезную историю/этимологию/фонетику; сохранить title+URL и
   дать короткий авторский пересказ. При недоступной сети — без него.
6. Занести в журнал `teaching`-запись (`target_ref`, `summary` по-русски).
   Дополнительные неформальные примеры — не evidence; evidence — только
   задания с ответом ученика.
