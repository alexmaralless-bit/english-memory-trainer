## Steps

1. Прочитать `curriculum show --topic <id>` и текущий `session status`.
   Проверить, что target совпадает с central/support ролью LessonArc.
2. Построить объяснение в порядке: живая ситуация и коммуникативная проблема
   → смысловой выбор/ментальная модель → компактная форма → необходимый
   контраст → 3–4 разобранных примера → типичные ошибки с причиной → граница
   правила и 1–3 частых полезных исключения с примерами → короткое
   retrieval-задание. Не ждать вопроса ученика об исключениях и не начинать
   со списка переводов.
3. Использовать curriculum memory_insights. Если их нет, исследовать только
   потенциально полезную историю/этимологию/фонетику; сохранить title+URL и
   дать короткий авторский пересказ. При недоступной сети продолжить без него.
4. Перед показом сохранить весь материал через `teaching rendered`.
5. Практика всегда идёт в порядке `session peek` → `session next` →
   `exercise rendered` → показать → `attempt record`. Не раскрывать ответ.
6. После оценённой попытки дать 1–2 дополнительных неформальных примера на
   ту же цель и короткий retry; они не становятся evidence без отдельной
   штатной попытки.
