## Steps

1. `curriculum show --topic <id>` (или `curriculum lexicon` для лексической
   единицы) — прочитать авторский can_do/значение/контексты.
2. Объяснить ученику своими словами, опираясь ТОЛЬКО на прочитанное.
3. Если тема совпадает с текущим предъявленным шагом (`session peek`) —
   продолжить обычной подачей задания (`exercise rendered` → `attempt record`).
   Формулировка задания НЕ должна содержать подсказок (не указывать в
   скобках нужную форму/местоимение и т.п.) — только контекст, достаточного
   для самостоятельного ответа.
4. После оценённой попытки по теме предложить ученику 1-2 дополнительных
   неформальных примера в чате на ту же цель (typical_errors из
   `curriculum show` — хороший источник) — без `exercise rendered`/
   `attempt record`, явно как дополнительную тренировку, которая не
   становится evidence и не отражается в mastery/score.
