Ten accepted live policies

generation@1, control@1, scoring@1, scheduler@1, rubric@1, assessments@1, lessons@1, evidence@1, obligations@1 and tunables@1.

  • Session and placement manifests pin active versions for deterministic replay.
  • Only original exercise text is allowed; no borrowed passages or excerpts.
  • Production eligibility is checked against active usage and currency policy at delivery time.

Four non-blocking v2 candidates

OPEN-33–36 preserve the content-first extension boundary without turning ideas into current-version promises.

  • A versioned Reading/Writing exam profile for timed and optionally adaptive mock sessions.
  • Validated, atomic bulk exercise packs for growing the authored bank.
  • An explicit active-policy manifest before multiple live versions coexist.
  • External benchmark ingress and confidence-bearing TOEFL calibration after official results exist.
