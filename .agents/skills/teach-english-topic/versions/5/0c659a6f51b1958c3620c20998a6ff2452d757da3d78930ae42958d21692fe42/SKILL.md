## Steps

1. Прочитать `curriculum show --topic <id>` и текущий `session status`.
   Проверить, что target совпадает с central/support ролью LessonArc, и
   определить активный learner-facing профиль (`lesson_arc.profile`).
2. **Фреймы перед формой.** У `curriculum lexicon` нет фильтра по
   `frame_of`/теме, поэтому источник связи — `topic.lexicon` из `curriculum
   show`: среди его id фреймы темы — это единицы с префиксом
   `chunk.<topic-code>.`. Получить их полные записи через `curriculum lexicon
   --type chunk` (при необходимости сузить `--cefr`/`--band`/`--limit`) и
   оставить те, чей id входит в `topic.lexicon`. Если фреймы есть, показать
   4–6 из них (предпочитая `CORE`/`HIGH`) — `title` со слотом `___` и
   `meaning_ru` — ДО компактной формы; затем retrieval bridge: попросить
   ученика напечатать два фрейма по русской реплике (смысл/ситуация), не
   показывая форму. Тема без фреймов (`frame_of` на неё отсутствует) этот шаг
   пропускает.
3. Форма объяснения зависит от профиля. `program_lesson` сохраняет полную
   дугу: живая ситуация и коммуникативная проблема → смысловой выбор/
   ментальная модель → компактная форма (после уже показанных фреймов на шаге
   2, не раньше) → необходимый контраст → 3–4 разобранных примера → типичные
   ошибки с причиной → граница правила и 1–3 частых полезных исключения с
   примерами → короткое retrieval-задание. Не ждать вопроса ученика об
   исключениях и не начинать со списка переводов. Для `practice`,
   `spaced_review` и `drill` — после фреймов дать целевую форму ОДНОЙ строкой;
   контраст, разбор примеров, исключения и причины ошибок переносятся в
   дебриф занятия (владеет им вызывающий skill — `run-english-session`,
   `run-spaced-review` или `run-drill-block` — не дублировать здесь).
4. Использовать curriculum memory_insights. Если их нет, исследовать только
   потенциально полезную историю/этимологию/фонетику; сохранить title+URL и
   дать короткий авторский пересказ. При недоступной сети продолжить без него.
5. Перед показом сохранить весь материал через `teaching rendered`.
6. Практика всегда идёт в порядке `session peek` → `session next` →
   `exercise rendered` → показать → `attempt record`. Не раскрывать ответ.
7. После оценённой попытки дать 1–2 дополнительных неформальных примера на
   ту же цель и короткий retry; они не становятся evidence без отдельной
   штатной попытки.
