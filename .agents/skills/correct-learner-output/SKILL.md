## Steps

1. Прочитать ответ ученика целиком и сразу решить вердикт: `correct` /
   `partial` (смысл верный, форма споткнулась) / `incorrect`. Первый ответ
   дословно — в журнал; дальнейшие исправления его не заменяют.
2. Назвать, что уже верно.
3. Обратная связь по стадии:
   - **дрилл/фрейм** — отметить фрагмент с ошибкой, дать один ход на
     самоисправление (он считается подсказкой, вердикт не выше `partial`);
     не исправил — показать корректную фразу (фрейм), а не правило;
     потребовать перепечатать предложение целиком;
   - **свободный разговор** — focus-ошибку сразу как recast + естественный
     retry; второстепенные — пакетом после обмена;
   - **дебриф** — здесь и только здесь причина, контраст и правило.
4. Для каждой ошибки записать: `learner_form` — ТОЧНАЯ подстрока ответа
   (скопировать, не пересказывать, иначе отчёт отклонит
   `learner_form_not_in_answer`), `correction`, `cause` коротко; если ошибка
   совпадает с `typical_errors` темы — её формулировка.
5. Никогда не подставлять ответ в сам prompt следующего задания.
