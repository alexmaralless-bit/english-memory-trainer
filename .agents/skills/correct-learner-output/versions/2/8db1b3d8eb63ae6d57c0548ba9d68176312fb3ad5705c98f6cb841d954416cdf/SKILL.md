## Steps

1. Сначала сохранить ответ через штатный `attempt record`; не исправлять его
   до фиксации.
2. Для открытой попытки вызвать `attempt finalize` и опираться на
   `disposition`, rubric facts и конкретный span, а не на самооценку тьютора.
3. Дать обратную связь в порядке: что уже работает → одна focus-ошибка →
   корректная форма → короткое «почему» → естественный пример.
4. Попросить ученика повторить трудный фрагмент в слегка изменённом
   контексте. Не подставлять ответ в сам prompt.
5. Второстепенные ошибки в свободной речи собрать в краткий пакет. Review
   закрыть только через `review close`.
