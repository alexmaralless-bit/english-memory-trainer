# П.2e — задание для Codex: тела тем B1–C2

> Дата постановки: 2026-07-22. Заказчик: владелец (через Claude).
> Роадмап: `wiki/roadmap.md` строка П.2e (next), запись 74/77.

## Цель

Каркас B1–C2 принят (П.1e): **122 темы без тел** — валидатор перечисляет каждую
(`warn: topic <id>: body not yet authored`). Твоя задача — наполнить тела по образцу П.2 (A1–A2).
Ученик готовится к **TOEFL (B2–C1)**; рабочий и бытовой язык равноправны.

## Порядок работы (важен)

**B1 → B2 → TOEFL-темы (внутри своих уровней) → C1 → C2**, батчами с коммитом после каждого уровня.

## Что такое «тело» (по образцу существующих A1–A2 тем)

К каждой теме добавить:

1. **`mastery_criteria`** (schema_version 1, по канону scoring §3b): `per_dimension` для КАЖДОЙ
   dimension каркаса (`active_threshold`, `independent_attempts`) + блок `mastered`
   (`all_required_active`, `retention_stability_days`, `retention_confirmations`). Пороги — авторские
   разумные (у A1–A2: threshold 70–75, attempts 2, retention 30/2); на C1–C2 пороги могут быть выше.
2. **`typical_errors`** — 2–5 ошибок **русскоязычной интерференции** для этой темы (кальки,
   ложные друзья, порядок слов, артикли, вид/время). Свои формулировки, конкретные.
3. **`examples`** — 2–4 авторских примера в контексте трека (работа/быт/академический).
   Для TOEFL-тем: короткие **авторские** академические мини-фрагменты (2–4 предложения),
   никаких заимствованных текстов/экзаменационных материалов — вечное правило own-text.
4. **`contexts`** — 1–3 смысловых контекста (по образцу: `status-update`, `team-introduction`…;
   для TOEFL — например `academic-passage`, `integrated-writing`, `discussion-board`).
5. **`lexicon`** — ссылки ТОЛЬКО на существующие единицы из 886, где реально уместно
   (многие A1–A2 chunks живут и в B1-контекстах). Пустой список допустим и честен:
   академический лексикон придёт с П.4e. **Новые единицы не заводить.**
6. **`explanation_language`** — `ru-allowed` (B1) / по твоему решению выше (обоснуй в отчёте).

## Жёсткие ограничения

- **Каркасные поля не трогать байтово**: `id`, `cefr`, `track`, `module`, `can_do`,
  `advisory_prerequisites`, `dimensions`, `frequency_tier` существующих тем неизменны;
  тела только ДОБАВЛЯЮТ поля. A1–A2 файлы и их тела — read-only.
- `curriculum/lexicon/**`, `tracks.yaml`, `levels.yaml`, `curriculum/modules/**` — read-only.
- **`src/`, `tests/`, `wiki/` не редактировать**; противоречия канона — предложениями в отчёте.
- Никаких фазовых маркеров [PD-2026-07-22]; никаких частотных полей/source_refs (П.4b).
- Корневой `Irregular Verbs.md` не трогать.
- mastery_criteria обязана покрывать **каждую** dimension каркаса темы — отсутствие критерия
  на required dimension валидатор считает ошибкой (для authored-уровней). NB: уровни B1–C2
  сейчас НЕ в `AUTHORED_LEVELS`, поэтому полные body-проверки валидатора на них не включатся —
  пиши тела так, будто включатся: владелец расширит `AUTHORED_LEVELS` после приёмки,
  и программа обязана остаться валидной.
