## NAWL provenance and selection

Roadmap P.4e stated that NAWL had already been pinned during P.4b. The repository did not contain a
NAWL artifact entry: `_provenance.yaml` and the P.4b handoff explicitly listed NAWL as unused. P.4e
therefore pins the actual official artifact before consulting it:

| Field | Value |
|---|---|
| id | `nawl@1.2` |
| artifact | `NAWL_12_lemmatized_for_teaching.csv` |
| sha256 | `1790b0fa22c5815ebf5a9a15c9363c03a6e906c77bf217f99033734f1459137b` |
| license | CC BY-SA 4.0 |
| encoding | Windows-1252 |

The official page describes 957 words, while the verified teaching CSV contains 959 non-empty unique
headwords. The manifest records this discrepancy and treats the pinned bytes as authoritative for
reproduction.

P.4e does **not** dump all 959 headwords into the curriculum. It selects a stable cross-domain core that
can be trained naturally through the accepted B1-C2 and TOEFL topics. Narrow medical, chemical,
mathematical, and biological terms remain material for vocabulary-in-context practice rather than
becoming mandatory lexical targets.

Of the 226 additions, **182 words are NAWL members**: all 181 entries in the three academic catalogs
plus `word.generalize` in the TOEFL catalog. The other 24 TOEFL words were authored because they name
skills the accepted track explicitly teaches (`attribution`, `evidence`, `premise`, `rebuttal`, `warrant`,
and related terms). All 206 new words receive a numeric Zipf value only from pinned `wordfreq@3.1.1`.

The corpus tool now reads the pinned NAWL file with an explicit UTF-8 then Windows-1252 fallback and
records `nawl@1.2` as membership provenance. NAWL membership never produces a numeric score. The full
lexicon has 649 measured items and 463 deliberately unmeasured items; source membership totals are
NGSL 304, BSL 171, and NAWL 195.

## Reproduction

The following command reproduces the report's content counters from committed YAML:

```powershell
@'
from collections import Counter
from pathlib import Path
import yaml

lexicon_files = [p for p in Path("curriculum/lexicon").glob("*.yaml") if not p.name.startswith("_")]
items = [x for p in lexicon_files for x in yaml.safe_load(p.read_text(encoding="utf-8"))["lexical_items"]]
new_names = {"academic-b1.yaml", "academic-b2.yaml", "academic-c1-c2.yaml", "toefl-reading-writing.yaml"}
new_items = [x for p in lexicon_files if p.name in new_names
             for x in yaml.safe_load(p.read_text(encoding="utf-8"))["lexical_items"]]
topics = [t for p in Path("curriculum/topics").glob("*.yaml")
          for t in yaml.safe_load(p.read_text(encoding="utf-8"))["topics"]
          if t["cefr"] in {"B1", "B2", "C1", "C2"}]
topic_refs = [r for t in topics for r in t.get("lexicon", [])]
links = yaml.safe_load(Path("curriculum/lexicon/_suggested-topic-links.yaml").read_text(encoding="utf-8"))["links"]
new_ids = {x["id"] for x in new_items}

print("total", len(items), "new", len(new_items))
print("new levels", Counter(x["cefr"] for x in new_items))
print("new types", Counter(x["type"] for x in new_items))
print("all levels", Counter(x["cefr"] for x in items))
print("priority", Counter(x["curriculum_priority_band"] for x in items))
print("measured", sum("frequency_score" in x for x in items),
      "bands", Counter(x["frequency_band"] for x in items if "frequency_band" in x))
print("source membership", {s: sum(s in x.get("source_refs", []) for x in items)
      for s in ("ngsl@1.2", "bsl@1.2", "nawl@1.2")})
print("advanced topics", len(topics), "refs", len(topic_refs),
      "unique refs", len(set(topic_refs)), "empty", sum(not t.get("lexicon") for t in topics))
print("new direct", len(new_ids & set(topic_refs)),
      "new advisory", len(new_ids & {link["lexical_item"] for link in links}))
'@ | .venv/Scripts/python.exe -
```

## Validation and known repository failures

P.4e-specific checks pass:

- corpus `--check`: pass, 649/463/0;
- curriculum validation: `curriculum valid: 275 topics, 1112 lexical items`;
- lexicon/corpus/content focused suite: 40 passed;
- Ruff on the modified Python test/tool files: pass;
- all 226 new IDs unique and advisory-linked;
- all 181 academic-catalog words and TOEFL `generalize` verified against the pinned NAWL bytes.

The full repository `pytest -q` run executes the complete suite and ends with two failures outside P.4e:

1. `tests/cli/test_cli.py::test_registry_matches_published_surface` — concurrent uncommitted memory work
   publishes `memory.render`, `memory.rebuild`, and `memory.check` but has not updated its exact CLI
   registry expectation.
2. `tests/curriculum/test_program.py::test_real_program_validates_clean` — a pre-existing P.1e assertion
   requires at least one `body not yet authored` warning after P.2e authored all 122 bodies.

The full `ruff check .`, `ruff format --check src tests`, and `mypy src` commands are likewise blocked only
by the same uncommitted memory increment (`cli/app.py` and `memory/engine.py`: formatting/import order,
line length/ambiguous Cyrillic characters, and one `TargetState | None` assignment). P.4e's modified Python
files pass their focused Ruff checks. P.4e does not edit or absorb the concurrent memory work.

The test `test_every_a1_a2_module_has_at_least_five_work_frames` previously built its module set from all
levels and then asserted that the set contained exactly 16 A1-A2 modules. Adding legitimate advanced
chunk links exposed the mismatch. It now filters topics to A1/A2 before applying the unchanged minimum of
five; the test name, counted scope, and exact-16 assertion are aligned.
