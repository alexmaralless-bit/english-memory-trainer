## Обязательные утверждения (MUST — из §2–5 assessments)

- **Lifecycle**: `start`→`answer` (checkpoint → IN_PROGRESS)→`resume` (в окне)→`submit` (терминальный). Нелегальные переходы отклоняются стабильной ошибкой (submit из STARTED; answer/abandon после терминала; второй активный start).
- **Идемпотентный submit**: повтор возвращает сохранённый результат и НЕ порождает новых событий.
- **Потолок `origin=placement` = ACTIVE**: ответь на все 3 грамматических item'а по `grammar.be.identity` верно, `submit`, затем `fold_scores` — цель должна быть **ACTIVE, а не MASTERED** (три CONFIRMED дали бы MASTERED, но потолок кэпит), с audit `placement-ceiling`. Неверные ответы никогда не наказывают.
- **Exposure capture-into-event + down-weight на повторе**: заверши/оставь первый placement, начни ВТОРОЙ, ответь на те же item'ы — re-seen item'ы должны быть down-weighted (обнулены), их вклад non-contributing; применённый вес виден в событии checkpoint/scored (capture-into-event). Второй submit не добавляет mastery по уже виденным.
- **Replayable `PLACEMENT_EXPIRED`**: начни placement, продвинь FixedClock за `resume_window` (48 ч), `resume` — placement терминализуется `EXPIRED` детерминированным `boundary_at` (= last_activity_at + окно, НЕ по sweep-часам), resume отклоняется. Проверь и `sweep_expired_placements` (идемпотентно: повтор ничего не минтит).
- **Self-assessment объектом**: `decline` с `{"schema_version":1,"levels":{"grammar":"A2","reading":"B1"}}` → `self_reported_levels` ровно эти навыки; **скаляр `"A2"` отклоняется** стабильной ошибкой; частичный объект оставляет отсутствующие навыки `unknown` (не дефолтит).
- **Детерминизм**: два независимых прогона (свои БД) байт-в-байт равны по `canonical_json`.

Любой пробел (поле/поведение, которого модуль не даёт) — **`@pytest.mark.xfail(strict=True, reason="2.6 finding: ...")`**, как в tutor-swap. Не чини `src`.
