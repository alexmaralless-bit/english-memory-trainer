### Engine/agent boundary

The agent may submit only concrete finding codes with verified UTF-8 spans and optional stable error refs. The payload
explicitly forbids agent-supplied criterion satisfaction, level, score, `correct`, outcome, severity, penalty, or mastery delta.
The engine:

1. resolves the pinned profile;
2. runs closed machine checks;
3. validates and dispositions subjective observations;
4. sums policy-owned positive finding units;
5. applies the policy-owned severity ceiling to exactly one criterion per error;
6. maps each criterion to one of four levels;
7. aggregates integer PPM with `ROUND_HALF_EVEN`;
8. atomically settles the attempt and emits `EVIDENCE_ADDED` when contributing.

### Numeric calibration

The v1 profile weights are concrete, executable policy values, not empirical claims. They are authored starting defaults and
must change only through a successor policy version after real-use calibration. No additional product fork was introduced by
choosing the initial integer weights.

### Owner integration dependencies

The payload intentionally does not change runtime code. The owner hook in 2.3 must:

- validate and register `rubric-v1.yaml` as kind `rubric` during curriculum activation;
- pin a non-null rubric version in new Session Manifests;
- resolve explicit/default refs before scoring and never fall back from a missing pinned version to active;
- persist `exercise_form`, applicable criteria, machine-check inputs, target surfaces/requirements, and their rubric-input
  hash with `EXERCISE_RENDERED`;
- validate UTF-8 spans, finding codes, error refs, and machine results;
- settle attempt aggregate + assessment/audit + contributing `EVIDENCE_ADDED` in one UoW;
- use graded `score_ppm` as the quality factor under existing session/rubric caps;
- preserve the existing semantic-identity and CreditAllocation rules.

The current scoring fold reads `correct` as a Boolean and does not multiply by `score_ppm`. PD-2 B therefore requires an
explicit 2.3 consumer change; otherwise the accepted four-level scale would be collapsed to binary.
