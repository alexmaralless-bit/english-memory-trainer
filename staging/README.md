# Staging — inbox перед каноном

> **Status**: process
> **Last updated**: 2026-07-19

Staging — не канон (Принцип 6, [[../wiki/README]]). Здесь оседает сырьё: саммари разговоров и принятых решений. Источник истины всегда в `wiki/` и `docs/`; journal — provenance («почему так решили»), к нему возвращаются при археологии, но на него не ссылаются как на норму.

## journal/

- Один файл на сессию: `journal/YYYY-MM-DD-<slug>.md`.
- Append-only: старые записи не редактируются и не удаляются.
- Формат свободный, но обязательно: дата, контекст, принятые решения с `[PD-YYYY-MM-DD]`, отложенные вопросы (→ [[../wiki/OPEN]]).
- Пишется в конце содержательной сессии проектирования или по запросу.
